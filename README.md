# ゆめいろフレンズ

スマートフォンのブラウザ（縦画面）で遊ぶ、オリジナルの3Dファンタジー育成・冒険ゲームです。
初回に読み込んだあとは**オフラインでも主要な遊びがすべて動きます**。課金・広告・外部通信は一切ありません。

**公開URL: https://daichiyutani-jpg.github.io/yumeiro-friends/** （`main` に push すると GitHub Actions でテスト → ビルド → 公開）

- 技術: Vite 8 / React 19 / TypeScript 7 / three.js 0.187 + @react-three/fiber 9 / zustand 5
- セーブ: 端末内の IndexedDB（バージョン付き・移行処理あり・本体＋バックアップの2重保存）
- 3Dモデル・音・アイコンはすべてコードで生成（外部の画像・音声・モデル素材は使っていません）

## 1. 起動・ビルド・テスト

Windows の PowerShell では `npm` が動かない環境があるため、`npm.cmd` を使ってください（コマンドプロンプトや mac/Linux では `npm` で可）。

```bash
npm.cmd install
```

```bash
npm.cmd run dev
```
開発サーバー（http://localhost:5173）。開発中は Service Worker を登録しません。

```bash
npm.cmd run build
```
型チェック → `dist/` へ本番ビルド → `dist/sw.js`（Service Worker）を生成。

```bash
npm.cmd run preview
```
本番ビルドを http://localhost:4173 で確認（オフライン確認はこちらで行う）。

```bash
npm.cmd test
```
ゲームロジックとセーブのテスト（vitest、44件）。

```bash
npm.cmd run typecheck
```

### スマートフォンで試す
1. PC と同じ Wi‑Fi にスマホをつなぐ。
2. `npm.cmd run build` のあと `npx.cmd vite preview --host` で起動し、表示された `http://<PCのIP>:4173` をスマホで開く。
3. Service Worker とホーム画面追加は **https か localhost でしか動きません**。LAN の http では「遊ぶ」ことはできてもオフライン化はされません。オフライン・PWA を実機で試すには `dist/` を GitHub Pages などの https 環境に置いてください（`base: './'` なのでサブディレクトリでも動きます）。

### PWA としてインストール
- iPhone Safari: 共有ボタン →「ホーム画面に追加」
- Android Chrome: メニュー →「アプリをインストール」/「ホーム画面に追加」

### オフライン確認の方法
1. `npm.cmd run build` → `npm.cmd run preview` で開き、一度タイトル画面まで表示する（ここで全ファイルがキャッシュされる）。
2. 「せってい」→ オフラインの欄が「✔ オフラインでも あそべる じゅんびが できています（9/9 ファイル）」になっていることを確認。
3. preview サーバーを止める（または DevTools の Network を Offline にする）。
4. ページを再読み込み → タイトルが表示され、続きから遊べれば OK。

### セーブの初期化
- ゲーム内: 「せってい」→「セーブデータを ぜんぶ けす」（確認が2段階あります）。
- ブラウザ側: DevTools → Application → IndexedDB → `yumeiro-friends` を削除。
- 消す前に「せってい」→「ファイルに ほぞん」で JSON に書き出し、「ファイルから よみこむ」で戻せます。

## 2. 操作方法

| 場面 | 操作 |
|---|---|
| 森の移動 | 画面の左下あたり（横半分・下4割）のどこかに指を置くと、そこにスティックが出るので そのまま動かす / 行きたい地面をタップ（自動で歩く）/ PC は矢印キー・WASD |
| 調べる・開ける | 近づくと右下の丸いボタンが「🎁 あける」「🔎 しらべる」などに変わるので押す（PC はスペース）。宝箱や仕掛けを直接タップしても、そこまで歩いて調べます |
| 森のメニュー | 左上「メニュー」: 進み具合・チーム変更・町へ帰る |
| 町に帰る | 森のスタート地点の虹のゲート、またはメニューの「まちへ かえる」 |
| まちづくり | 家具を選ぶ → 黄色い範囲をタップして置く → 置いた家具をタップで「うごかす・まわす・しまう」 |
| チュートリアル | 画面上部の妖精の案内に従う。「スキップ」でいつでも飛ばせ、「せってい」から再表示できる |

## 3. オフラインで動く機能（すべて実装済み）

- 主人公の作成（名前・髪型・髪/目/肌の色・最初の服）と着せ替え（7部位）、プリンセス変身（ドレス・ティアラ・ガラスのくつが揃うと変身）
- なかま 12種（＋進化形 25種＝図鑑 37種）。入手方法: 最初の1体 / たまご / 森での出会い / 素材で「よびかける」
- おせわ（ごはん・なでる・あそぶ・ブラッシング・おひるね）。病気・仲良し度の減少は**ありません**
- レベル・経験値、仲良し度に応じたリアクション/特別ポーズ解放
- 分岐進化（1体につき2〜3通り）。進化は確認つき、あとから元に戻して別の姿を選び直せる（素材は戻らない）
- さくらの森の冒険: 宝箱7、仕掛け6（花のつる・光る小川・暗い洞窟・大岩・高い木・花のスイッチ順番）、出会い4、拾える素材12（10分で再出現）、隠し通路（生け垣の切れ目→大岩の奥の宝箱）、町へ戻るゲート
- 能力が必要な仕掛けは**すべて代わりの方法あり**（道具を店で買う／花びらを供える）。必要な能力の仲間がいない時は「チームを かえる」が出る
- チーム（最大3体）が後ろをついてくる
- コイン・素材・食べ物・種・道具の増減（足りない時は何も変わらない、マイナス不可）
- たまご（ゲーム内コインのみ・確率を画面に表示）、時間で孵化
- おはなばたけ（6区画、植える→時間で育つ→収穫）、仲間の「そざいさがし」（20分ごと、6個まで）
- まちづくり（家具14種、置く・動かす・回す・しまう、最大40個）。町では仲間が歩き回り、家具（ベンチ等）で休む
- ミニゲーム「はなつみ」（30秒、お題の花をタップ）
- おみせ（ごはん・種・道具・服・家具）とアトリエ（素材で服・家具を作る）
- ずかん、もちもの
- オフライン中の時間経過（ゲームを閉じていても卵・花壇・おてつだいが進む）。端末の時刻を戻してもゲーム内時間は戻らず、未来へ大きく進めても最大3日分まで
- 冒険の世界地図（さくらの森のみ遊べる。残り6つの世界は鍵マーク付きで「じゅんびちゅう」と表示し、選んでも入れない）
- 設定（効果音、大きい文字、動きを減らす、チュートリアル再表示）、手動セーブ、JSON書き出し/読み込み、2段階確認つき初期化、オフライン対応状況の表示
- ともだち機能の**おためし版**（下記）

## 4. 未実装のオンライン機能

画面上は「おためし」「みほん」と明示し、実際の通信は一切しません。

| 機能 | 現状 |
|---|---|
| 本物のともだち登録 | 未実装。QRコード欄は見た目だけの模様（読み取れない）、カメラボタンは無効 |
| 町の訪問 | 見本の友達2人（みみ・そら）の町を**見るだけ**。変更不可 |
| 交換 | 「おためしこうかん」。確認画面まで体験できるが、**本当の持ち物は増減しない** |
| サーバー・アカウント・クラウドセーブ | 未実装 |

子どもの安全のため、自由入力のチャット・位置情報・本名/学校名/電話番号の入力欄は**作っていません**（主人公の名前は端末内にだけ保存）。

## 6. 素材・ライセンス

- キャラクター・世界・名前・文章はすべてこのプロジェクトのオリジナル。既存作品のキャラクター・ロゴ・音楽は使っていません。
- 3Dモデル: three.js の基本図形（球・円柱・円すい等）をコードで組み合わせて生成。
- 効果音: Web Audio API でその場で合成。
- アプリアイコン: `scripts/make-icons.mjs` でPNGを生成（外部素材なし）。
- 一部の画面で絵文字を使っていますが、これは**端末のシステムフォント**で表示されるもので、画像として同梱していません（端末によって見た目が変わります）。
- 利用ライブラリ（すべて MIT）: three, @react-three/fiber, react, react-dom, zustand, vite, vitest, fake-indexeddb, typescript（Apache-2.0）。

## 7. ファイル構成

```
src/game/data      なかま・アイテム・服・家具・森の配置などのデータ
src/game/logic     ゲームのルール（状態を受け取って新しい状態を返す純粋関数）
src/save           IndexedDB への保存
src/state/store.ts 画面とルールをつなぐストア（自動セーブ・時間経過）
src/three          3Dモデルとシーン（森・町・主人公・なかま・家具）
src/screens        各画面
sw/sw-template.js  Service Worker（ビルド時にファイル一覧とバージョンを埋め込む）
tests              ロジック・セーブのテスト
```

## 8. 既知の制限・未確認事項

- **実機（iPhone Safari / Android Chrome）では未確認。** 確認は PC の Chromium ブラウザで 375×812 の画面サイズを再現して行いました。iOS でのホーム画面追加、セーフエリア、タッチ操作の感触は実機で確認が必要です。
- 性能はローエンド端末では未計測。描画解像度は最大1.75倍、影は円形の疑似影、木や花はまとめて描画（インスタンス化）して軽くしています。
- JS は1ファイル約1.3MB（gzip 約370KB）。初回読み込みはやや重めです。
- ブラウザで手動プレイ確認したのは、宝箱1つ・花のつるの仕掛け・町への帰還まで。他の仕掛け（小川・洞窟・大岩・高い木・スイッチ）、隠し通路、森での出会いは**ロジックのテストのみ**で、実際に歩いての確認はしていません。
- 新しい版を公開すると、「せってい」に「✨ あたらしい バージョンに する」ボタンが出て、押すと更新されます（遊んでいる途中で勝手に切り替えない）。
- iOS Safari は長期間開かないとサイトのデータを消すことがあります。大切なセーブは「ファイルに ほぞん」で書き出してください。
- 音は最初の操作のあとに鳴り始めます（ブラウザの自動再生制限）。
